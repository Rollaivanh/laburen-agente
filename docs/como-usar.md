## Funcionalidades Disponibles

### Servicios Principales

1. **ProductService**: Gestión de productos
   - Listar productos
   - Obtener detalles de un producto

2. **CartService**: Gestión del carrito
   - Obtener / Crear carrito
   - Agregar productos al carrito
   - Actualizar cantidades
   - Eliminar productos
   - Calcular totales

## Requisitos

- Variables de entorno configuradas en Wrangler:
  - `SUPABASE_URL`
  - `SUPABASE_KEY`
- Conexión a internet
- Cloudflare Workers disponible
